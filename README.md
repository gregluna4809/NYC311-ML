# NYC Civic ML

NYC Civic ML is a Python-based machine learning project for exploring New York City civic datasets, preparing structured data, training analytical models, and documenting insights that can support civic analysis and public-sector decision making.

## Technology Stack

- Python
- Jupyter Notebooks
- pandas and NumPy
- scikit-learn
- PostgreSQL
- Backend and frontend components planned for future phases

## Planned Roadmap

- Collect and document source civic datasets.
- Build raw-to-processed data preparation workflows.
- Explore baseline machine learning models.
- Add database storage for prepared datasets and model outputs.
- Develop backend APIs for serving analysis results.
- Develop a frontend interface for exploring civic insights.
